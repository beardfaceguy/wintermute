## Eight steps
1. Define purpose & scope — clear use case, success criteria, constraints. Link: https://lnkd.in/eekC6bwT
2. Build system prompt — critical step; strong prompt needed. Link: https://lnkd.in/d_qYCBT7
3. Choose LLM — balance speed, modality, strengths. Link: https://lnkd.in/eqRgsMZx
4. Integrate tools — makes it an agent; MCP/APIs/other agents. Link: https://lnkd.in/ezNsTfbD
5. Add memory — only if needed (history, research state). Link: https://lnkd.in/eeey5Cxr
6. Orchestrate things — control flow, routing, queues, agent-to-agent coordination. Link: https://lnkd.in/eKhmKYNp
7. Build a UI — only after prior steps. Link: https://lnkd.in/epRC64ku
8. Add testing & evals — continuous improvement loop. Link: https://lnkd.in/eGbzWMxf
